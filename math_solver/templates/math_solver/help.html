📚 Guía de Uso - App de Ecuaciones Diferenciales no Lineales

← Volver al Solver

Aprende a utilizar todas las funciones de nuestro solver de ecuaciones matemáticas

🚀 Inicio Rápido

1. Selecciona un Tipo de Ecuación

Elige entre las diferentes opciones en el panel izquierdo:

  • • Ecuación polinómica de segundo grado (Cuadrática): ax² + bx + c = 0
  • • Ecuación diferencial ordinaria de primer orden no lineal (Bernoulli): y' + P(x)y = Q(x)yⁿ
  • • Ecuación diferencial lineal de segundo orden con coeficientes variables (Cauchy-Euler): ax²y'' + bxy' + cy = R(x)
  • • Ecuación diferencial ordinaria de primer orden no lineal (Clairaut): y = xy' + f(y')
  • • Ecuación diferencial ordinaria de primer orden no lineal (Riccati): y' = P(x)y² + Q(x)y + R(x)
  • • Segundo Orden (Homogéneo/No Homogéneo): ay'' + by' + cy = g(x)

2. Ingresa los Parámetros

Completa los campos con tus valores matemáticos:

  • • Usa la paleta de funciones para insertar funciones matemáticas
  • • Los campos aceptan expresiones como 2*x + 3
  • • Usa x como variable independiente
  • • Las constantes como π, e, i están disponibles

3. Obtén tu Solución

Presiona el botón "Resolver Ecuación" y obtén resultados detallados con:

  • ✅ Pasos detallados del proceso
  • ✅ Formato matemático profesional
  • ✅ Verificación de soluciones
  • ✅ Persistencia de resultados

💡 Ejemplos Prácticos

Ecuación polinómica de segundo grado (Cuadrática)

Resolver: x² - 5x + 6 = 0

Parámetros: a=1, b=-5, c=6
Solución: x₁=3, x₂=2

Ecuación diferencial ordinaria de primer orden no lineal (Bernoulli)

Resolver: y' + (2/x)y = xy²

Parámetros: P(x)=2/x, Q(x)=x, n=2
Solución: y = 1/(Cx² - x³/3)

Ecuación diferencial ordinaria de primer orden no lineal (Riccati)

Resolver: y' = y² - xy + 1

Parámetros: P(x)=1, Q(x)=-x, R(x)=1
Solución: y = x + (e^(-x²))/(C - ∫e^(-x²)dx)

Ecuación diferencial lineal de segundo orden con coeficientes variables (Cauchy-Euler)

Resolver: x²y'' + xy' - y = 0

Parámetros: a=1, b=1, c=-1, R(x)=0
Solución: y = C₁x + C₂x⁻¹
Nota: Ecuación homogénea de Cauchy-Euler con raíces r₁=1, r₂=-1

Ecuación diferencial ordinaria de primer orden no lineal (Clairaut)

Resolver: y = xy' + (y')²

Parámetros: f(p) = p**2 (donde p representa y')
Solución General: y = Cx + C²
Solución Singular: También puede tener envolvente singular

Ecuación diferencial lineal de segundo orden con coeficientes constantes homogénea (Homogéneo)

Resolver: y'' + 4y' + 4y = 0

Parámetros: a=1, b=4, c=4
Ecuación característica: r² + 4r + 4 = 0
Raíces: r = -2 (raíz doble)
Solución: y = (C₁ + C₂x)e⁻²ˣ

Ecuación diferencial lineal de segundo orden con coeficientes constantes homogénea (Homogéneo) - Raíces Complejas

Resolver: y'' + 4y = 0

Parámetros: a=1, b=0, c=4
Ecuación característica: r² + 4 = 0
Raíces: r = ±2i (complejas conjugadas)
Solución: y = C₁cos(2x) + C₂sin(2x)

Ecuación diferencial lineal de segundo orden con coeficientes constantes no homogénea (No Homogéneo)

Resolver: y'' - 3y' + 2y = exp(x)

Parámetros: a=1, b=-3, c=2, g(x)=exp(x)
Solución homogénea: y_h = C₁e^x + C₂e^(2x)
Solución particular: Se busca usando método de coeficientes indeterminados o variación de parámetros
Solución general: y = y_h + y_p

Ejemplo con Condiciones Iniciales (IVP) - Bernoulli

Resolver: y' - 5y = -5x·y³/2, y(0) = 1

Parámetros: P(x)=-5, Q(x)=-5/2*x, n=3
Condiciones iniciales: x₀=0, y₀=1
Solución general: Primero se resuelve sin IVP
Solución particular: Se aplican las condiciones iniciales para encontrar la constante específica

❓ Preguntas Frecuentes

¿Qué variable debo usar?

Usa siempre x como variable independiente en tus expresiones.

¿Cómo ingreso fracciones?

Usa la notación 1/x o (numerator)/(denominator) para fracciones.

¿Puedo usar números complejos?

Sí, puedes usar I para la unidad imaginaria y expresiones complejas.

¿Qué pasa si hay un error?

El sistema mostrará mensajes de error detallados. Verifica tu sintaxis y asegúrate de usar los formatos correctos.

¿Se guardan mis datos?

Los datos se guardan localmente en tu navegador usando localStorage. No se envían a servidores externos.
